# 用原片建立局部质感基准

在 Skill 目录内运行。使用现有视觉脚本的 Python 环境、FFmpeg 和 FFprobe。

```bash
python scripts/decompose.py lookdiff 原片.mp4 Blender渲染.mp4 输出目录
python scripts/decompose.py compare 原片/scene3d.json 渲染/scene3d.json --out 输出目录
```

整段输入从同一剪辑入点开始，使用相同的编码画幅和显示方向。帧率可以不同，按各自的逐帧显示时间戳匹配。同一镜头内约每 0.4 秒取一次代表帧，另取紧邻帧及约 0.16 秒外的邻帧复测。报告中的时间以原片输入首帧为零点。复测节奏会漏过极短闪动，可用两份对应时刻的 `scene3d.json` 指定代表帧核对。两个 JSON 记录的代表帧充当同步锚点，允许一边为长原片、一边为短渲染。原生媒体缺失、画幅不同、HDR、同镜独立邻帧不足等情况会给出原因。

移动原片或渲染后，可为 `compare` 追加 `--reference-video` 或 `--render-video`，分别指定对应视频的新路径。分发版生成的 `scene3d.json` 会用 SHA-256 验证重绑文件。旧 JSON 在原位置仍可使用，迁移后需重跑 `scene3d`。同时保留每份 JSON 同级的代表帧 PNG。

## 从读数到试渲染

1. 打开整段的 `lookdiff.md` 或代表帧的 `compare_report.md`。先看全帧位置图和配准结果。局部对照左为原片、右为渲染，每边保留原生像素。框的格式为左上角 x、y、宽、高。存在大幅位移或遮挡时优先复核相机、主体与同步关系。
2. 查看一个高优先级框的原片范围、渲染读数、差值与检测下限。同片邻帧波动、像素分辨能力和配准误差决定该处可分辨的变化。排序还考虑局部对比、跟踪质量、多个采样时刻的一致性和跨度。有物件候选时，报告给出像素长度相对物件框宽度的比例。自动轮廓框是尺寸代理，物体身份与深度仍需对照画面确认。
3. 按同一条件重渲染，仅改变报告指向的一个参数。若渲染亮斑比原片宽，先单独减小 Area Light 的 Size，同时复测亮斑宽度与投影边界。若投影已经吻合，恢复灯尺寸，再单独降低材质 Roughness。比较两个试验对目标区域和相邻区域的影响。对非周期颗粒比较频谱和密度统计，允许两边使用不同随机种子。
4. 翻看 `lookdiff.json` 的 `windows` 和 `ranked_findings`，或 `compare_report.json` 的 `local_appearance`。`resolution_floor` 与该行指标同单位，`match_error_px` 为配准往返误差，`confidence` 是相对排序分数。时间区间是有测量支持的最早和最晚采样时刻。遮挡、重复图案和变形都可能产生错配，零往返误差也需检查裁片。检测证据进入默认报告，原有 `--strict` 仍读取原有验收项的裁决。

| 可观察属性 | 读数与适用范围 |
| --- | --- |
| 纹理 | 原生像素周期、模 180° 的条纹轴向、规则度、非周期特征波长、主轴、细纹强度和分区聚集度。接近奈奎斯特频率、低对比或被编码抹掉的细节可能无法分辨。 |
| 边缘 | 稳定线段法向的亮度 10% 至 90% 过渡宽度、通道边沿分离、低亮度对比色界宽度，以及沿线的轮廓起伏和断续。 |
| 灯光及反射 | 局部明度、Lab 色偏、明暗跨度、封闭亮斑和暗斑的半幅等效直径，以及暗斑边界宽度。底色图案也会形成亮斑。缺少可信的同一斑点时保留成因待查。 |
| 清晰度及运动 | 4×4 网格给出轮廓宽度差异的空间覆盖。在有物体运动和稳定跟踪时，比较运动补偿前后的细纹相关。缺少运动视差时无法单凭区域位置指认前后景。 |

分布广、以高频为主的残差会触发一次原片 H.264 重编码对照。若残差相似则显示编码与材质无法分离。其他编码器、不同锐化处理或幅度极弱的全画面细节仍可能混淆。先用原始渲染或同编码条件复测。

## 在其他项目复验

准备清单，把同一项目的版本、剪辑和衍生片放在同一组。每个源视频至少能连续解出五帧。清单格式如下。

```json
{
  "development": ["开发项目.mp4"],
  "holdout": ["独立项目.mp4"],
  "cases": ["texture_spacing", "texture_orientation", "highlight_width", "background_softening", "codec_only", "identity", "smooth", "random_seed"]
}
```

```bash
python scripts/evaluate_lookdiff.py 清单.json 视频目录 验证目录 development
# 固定检测器和计分口径后，再运行一次留出组
python scripts/evaluate_lookdiff.py 清单.json 视频目录 验证目录 holdout
```

每个案例在真实视频片段上生成一对短视频。改动区域由固定种子决定，检测器只读取视频。阳性样本取全段前三条，框中心落入真值区域且交叠达到取样框面积的一半算定位命中。该框还需属性和差值方向均正确才算方向命中。阴性样本出现任何返修条目即记误报。逐例材料和报告写在项目子目录，总表记录两个文件指纹与分子、分母。对粗糙度、灯光尺寸等物理参数的归因，需要另外用真实 Blender 工程的单变量试渲染验证。

本版在四个整项目留出的受控素材上，前三条定位命中 16/16，位置、属性和方向同时命中 15/16，阴性误报 3/16。一次编码变化和两次随机种子变化触发了错误建议。局部读数用于安排试渲染，由原尺寸裁片及复渲结果确认成因。
