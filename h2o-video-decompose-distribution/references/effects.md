# 原片重点效果与逐项验收

## 从连续画面建立清单

总负责人先只看原片。原速看完目标范围，逐镜写下第一眼最影响观感的变化；再看慢放、切点两侧及原尺寸裁片，补短暂或细微的效果。用户点名项直接列为必验。每镜登记观察结果及源证据。把这些记录与首次盘点独立对照，补登遗漏，并保留初次漏掉的项目。后续审片发现清单以外的明显差异也要补登。

每项写为「起止显示时间｜哪个主体相对什么发生什么变化｜原片依据｜可观察的通过条件｜责任段」。例如「焦点从前景文字转向后方人物时，两个区域的锐度顺序互换；转移时刻和持续时间与原片相符」。同一效果跨段共用一个标识，分段保留局部测量，总装重新覆盖它的完整时段。效果之间可以重叠。

| 效果 | 测量对象及可用证据 |
| --- | --- |
| 运动与节奏 | 背景选多块稳定结构，独立运动的主体另设区域。用运动跟踪比较平移、旋转、推拉、急停、反复抖动及相邻动作的时间关系，同时核对全片连续性。 |
| 空间与透视 | 两版各自确定同名平面和角点，比较中心对齐后的原始投影形状及其时序。多深度视差另跟踪前后层，三维镜头同时用三维几何和渲染对照。 |
| 清晰度与成像 | 拖影测量多个方向的边缘与纹理展宽。景深至少指定两个清楚标识的层次，比较各自的边缘宽度、层间差及变化顺序。尾迹的前后指向、透明重影和透焦混合可单列人工项。 |
| 光色、材质与质感 | 用局部质感诊断、三维光度对照（`compare --strict`）与工程静态审计（`audit-blend --strict`）核对纹理、光色、间接溢光、体积光雾、表面反射与局部明暗反差，再原速查看高光、反射或颗粒如何随主体运动。凡原片存在显著自发光溢光、光泽/镜面反射、大气雾或跨明暗景别过渡，必须单列「光影层次、溢光与反射氛围」作为必验重点效果项，不得只验收构图、轨迹与文字。 |
| 图层、显隐与转场 | 对固定区域从初始稳定背景测出现、消失；复杂遮挡、蒙版和同色替换结合主体连续性及局部慢放判读。 |
| 声画配合 | 单一清晰击点比较两版“声音瞬态减去画面冲击”的时间差。多声部、口型、跨镜余音按声音拆解表与试听逐项复核。 |

遇到清单之外的效果，记录其可见特征和通过条件，选能验证它的读数或人工对照。技术读数必须与该条通过条件对应。多项复合判断拆开登记；有剩余语义需要审片时设 `review_required`。

## 运行与输入

两版视频起点按内容对齐，区间使用相对第一显示帧的秒数，左闭右开。各自读取原始显示时间，包括变帧率，取两版显示事件的并集。两版可独立标区域以适配裁切、不同画幅或构图。区域须是同一个可辨认的对象。缺少可靠配对时用原帧重新标注或人工复核。

~~~sh
python scripts/decompose.py effects 原片.mp4 实际导出.mp4 重点效果.json 验收目录
~~~

~~~json
{"effects":[
  {"id":"焦点转移","subject":"前景标签和后方人物","mode":"focus","range":[2.0,3.6],
   "criterion":"转焦前后两处清晰度顺序、转移时刻和持续时间与原片一致",
   "evidence":"原片第2.0–3.6秒，标签笔画及后方人物衣领轮廓",
   "regions":[{"name":"标签","ref":[0.12,0.38,0.38,0.73],"rep":[0.14,0.4,0.4,0.75]},
              {"name":"衣领","ref":{"keys":[[2.0,[0.52,0.32,0.76,0.62]],[3.6,[0.46,0.34,0.70,0.64]]]}}]}
]}
~~~

- `mode` 支持 `motion`、`perspective`、`trail`、`focus`、`visibility`、`impact`、`manual`。位置为归一化左上、右下坐标。`rep` 省略时沿用 `ref` 的区域设定。移动区域可给两版分别写源时间关键帧，帧间线性插值。若主体快速转向或被遮挡，追加关键帧或分开标注可见区间。
- 自动配对优先核对双方纹理、特征分布与拟合误差。重建后纹理很不相同时，运动、景深和拖影可由审片者在具名区域的 `identity_evidence` 中记录已核对的同一主体及证据，允许两版各自测量；留有遮挡或混层疑义时设 `review_required: true`。运动区域固定在画幅上，或将区域设大以包含运动全程；跟随主体移动的裁片会抵消其屏幕位移。
- 透视可在区域中提供 `corners_ref` 和 `corners_rep`，各为首帧按左上、右上、右下、左下顺序标出的四对区域内归一化坐标。两版独立跟踪四角，比较原始投影。角点出画、消失或跟踪不可信时该区间待复核。
- 检查的空间尺度随主体尺寸归一化，测量容差计入拟合误差和原片近期波动。细纹低于检测分辨率、稀疏边缘、不同画幅里无法对应的内容要核对原尺寸裁片。方向性展宽给出轴向证据；判断沿运动的前拖或后拖要核对运动轨迹与可辨尾迹。两版帧率不同引起的单边曝光更新记录在运动复核区间。
- `manual` 用于新效果或已有专用工具的结果。把局部质感、三维渲染、声画对应或连续性报告的具体时刻及证据写入人工判断。画幅相关指标的通过只涵盖清单明示且有读数支持的属性。

## 复核、返修和总装

打开输出中的《逐项效果验收》和《同步审片》。后者支持原速与四倍慢放，原片在左。声音对照文件保留双方可用的独立音轨，可在播放器切换。逐帧数据保留源帧和显示时间、参考与导出读数、容差及缺测原因。连续异常归为事件，保留完整时间段和代表帧。

人工结论随同次运行的 `review_id` 提交，证据路径相对于复核文件；正文写明核对过的时段、主体和依据。

~~~json
{"review_id":"复制本次 effects.json 中的值","decisions":{"焦点转移":{"status":"需返修","reason":"2.80–3.03 秒前景笔画持续清晰，原片已转焦到后方衣领","evidence":"验收目录/证据-本次标识/001-同步对照.mp4"}}}
~~~

~~~sh
python scripts/decompose.py effects 原片.mp4 实际导出.mp4 重点效果.json 验收目录 --decisions 复核结论.json
~~~

复测可追加 `--previous 修前验收目录/effects.json`。命令核对原片及清单指纹，把修前需返修且本次通过的项目列为已修好。相同导出或不同清单不能用来证明已经修复。不同输入及检测版本分别保存证据，复核时可复用同一组测量。

退出码 0 为本清单通过，2 为需返修，3 为待复核。证据不足或原生时间范围缺失不能自动通过。发现差异后，原分段负责人记录源时间、可见差异、修改、重导及复测结果。声称“已修好”须具备同一项的修前证据及新版通过结论。整片交付同时核对逐镜清单完整性、适用专项结果、整合成片重点效果及整片连续性；分别报告已通过、已修好、仍需返修和缺证据的项。

## 复验

用 `python tests/test_effects.py 输出目录` 生成可复验的正常与故障对照。真实项目按类型独立选片，并留出至少一个未参与调参的完整项目。检验前仅看原片登记显著效果。分别统计首次分析遗漏、已标效果检出、定位偏差、误报、待复核和人工确认；已知缺陷若被放行，先修正并重测。阈值与实现固定后再跑留出项目，后续如据此调参，须更换留出项目。
