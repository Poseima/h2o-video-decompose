# 有原片的镜头连续性验收

用于实拍、三维、UI 和混合视频的审片。以同一时间起点的原片和实际导出为输入。局部修改优先传入含上下文的两条完整视频。只审局部时按秒指定原片时间范围，区间左闭右开，额外检查跨过两端的相邻帧。无原片时沿用既有审片流程。

```sh
python scripts/decompose.py continuity reference.mp4 export.mp4 review
python scripts/decompose.py continuity reference.mp4 export.mp4 review-window --start 7.5 --end 10.5
```

输入须已按内容同步。按显示时间戳分别解码两条视频的原生相邻帧。不同帧率的曝光区间内比较参考动作；先对照原片自身的运动、切镜和闪光，再判断复刻是否多出或错过事件。比较相机速度变化、反复抖动、双向跟踪误差、运动补偿后的结构残差以及九宫格内的光色变化。阈值为审片启发式；强视差、满屏运动主体、遮挡、刻意重定时都可能需要人工判断。

退出码 0 表示通过，2 表示需返修，3 表示待复核或缺测。读取本次命令的退出码和 `continuity.json`。该文件记录输入、范围、覆盖情况、判断与时间码。`pairs.json` 保存按帧的测量与跨片对应；像素误差来自缩放后的分析画幅，位移按画幅长边归一化。证据视频左侧为原片、右侧为导出，每段附原速与四倍慢放。

人工复核时查看证据和实际导出，核实原片是否有同一动作、方向、时间和作用区域。复核文件使用本报告的 `review_id` 与候选 `id`，例如：

```json
{"review_id":"从报告复制","decisions":{"从报告复制候选ID":{"status":"通过","reason":"写明时间、区域及原片中对应的有意运动"}}}
```

用相同输入、区间及 `--decisions 文件.json` 重跑。已确认缺陷标「需返修」。缺测不能通过人工结论覆盖，补齐时间、解码或对照材料后再测。重新导出后旧复核记录失效。最终整合片按全段重跑；未通过须注明时间与原因。

### 报告读法与复测

报告中的 `events` 把同类型、同区域的连续候选合并为时间段，逐帧判据保存在 `findings` 与 `pairs.json`。原生帧号从零开始。每个帧对的 `motion` 是长边归一化的中心水平位移、垂直位移、旋转弧度和相对缩放的自然对数。`structure` 是有效像素中运动补偿后亮度差超过 20/255 的比例，`mismatch` 是双向跟踪往返误差超过 2 分析像素的比例。九宫格按从左到右、从上到下排列，每个格依次记录结构残差占比、B/G/R 有符号变化中位数和往返失配占比。检测比较两片各自的帧间变化，素材的外观一致性仍由现有审片流程另行验收。

如交付本来就是长参考片的节选，明确指定对应范围，确保整个导出时长都被覆盖；输入起点不同时先准备与导出同一起点的参考节选。复测脚本 `python tests/test_continuity.py 输出目录` 会生成与具体项目无关的测试视频，检查状态、证据与退出码。

### 局部显露、消失与错时

连续性检测在实际导出的原生相邻帧上双向追踪，将跟踪失配、轮廓丢失、光流补偿色差、有效覆盖以及邻帧的局部波动一起比较。局部跟踪中断可单独触发「局部入画或遮挡待复核」。孤立的低纹理跟丢可信度低。匹配到两片边缘同色区域持续显露且时刻不同，可另报「连续入画时机偏差」。色带、范围和方向只是图像证据，遮挡物、人物身份及工程中实际的可见性仍需核实。

有框的 finding 使用相对于完整显示画幅的归一化 `bbox=[左,上,宽,高]`。同一时间可以同时出现运镜、光色及局部提示。原速和四倍慢放证据在右栏标出对应区域。逐帧复核区域从何处显露、是否连续、原片同处是否有对应事件。运镜候选的处理结论不覆盖局部候选。局部低置信度或错时进入待复核。报告版本变化后须用本次导出重新生成复核记录。

运行 `python tests/test_local_continuity.py 输出目录` 验证画内闪现、换位、消失和正常过窗等情况。可加 `--holdout 另一项目视频.mp4` 将同一批已知事件注入独立视频检验定位。局部检测在缩放后的画幅工作，极小或被遮挡的轮廓可能缺测。


版本 3 对小区域沿运动方向比较前后数帧的轮廓、颜色和明暗阶跃，报告「局部外观跨帧跳变」。持续可见的碎片在遮挡中失去追踪时，可报告「遮挡处可见轨迹中断」及最后可追踪帧。比对两片从同一画框边缘进入的可见区域时，同时核对颜色、位置、移动方向、位移和显露面积，匹配充分才估计「主体入画时机偏差」。偏移为复刻首次可追踪时间减原片时间，负值表示提前。一个主体的可追踪部位可能比其最早的可见像素晚出现。

证据右侧黄框为复刻区域，左侧青框为同时刻对照区域或原片该次入画区域。报告中 `reference_event_frame` 和 `reference_event_time` 指原片的对照帧，`offset_interval` 表示按两片采样间隔估计的时间范围。新提示默认待复核。若两片中的主体不同、动作源于正常遮挡或形体不可辨，审片记录应明确写出判断依据。确认具体换模和可见性开关需要额外工程证据。对已指出却没有对应框的问题，交付记录保留该时间和待复核原因；只有审片者核对过同一主体才能关闭该项。小、暗、完全遮挡、显露部位不同及同色干扰均可能导致漏报或错配。

运行 `python tests/test_subject_continuity.py 输出目录` 对比正常转身、部分及完全遮挡、同色物体入画和相应的受控异常。
