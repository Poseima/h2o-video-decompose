# `h2o-video-decompose-distribution` 能力边界与可扩展能力注册表

本文件是 `h2o-video-decompose-distribution` 的**能力边界单一事实来源（Single Source of Truth）**。在完成扫查（`scan`）并查看故事板与关键帧后，必须先对照本文件对目标视频逐镜、分层定级，明确「擅长什么、能做到什么程度、哪些超出当前高精度复刻边界」，再决定直接执行或先向用户前置沟通。

---

## 一、 核心原则：区分「拆解分析」与「高精度可编辑复刻」

同一段视频在**拆解分析**与**高精度可编辑复刻**上的能力边界完全不同：

| 任务类型 | 当前覆盖范围 | 主要交付物 | 当前边界限制 |
| --- | --- | --- | --- |
| **拆解分析**（`scan` + `soundtrack` + 视觉/光学精测） | **几乎所有视频均支持**（实拍、动漫、特效、UI、3D 均可） | 镜头与切点表、运镜/构图/光色分析、人声/BGM/音效三轨分离、音乐拍点与瞬态声画对应表（`av-events.csv`）、可复刻性简评 | 强混音串音可能降低弱音效置信度；模型通道无原生音频输入时须标「待听辨」；当前未内置本地高精度 ASR 语音转写校对 |
| **高精度可编辑复刻**（Remotion / AE / Blender 参数化路线） | 各等级均以指定范围 1:1 为目标。L1 可沿现有管线制作，L2/L3 需验证资源或其他重建路线 | 可编辑工程文件（Remotion / Web / AE / Blender `.blend`）、源时间对齐预览与成片、闭环量化验收记录 | 严禁直接复用/裁切/抠图原片像素；超出当前程序化建模、排版与着色能力边界的内容必须在开工前如实告知 |
| **3DGS 摄影测量 / 辐射场重建路线（Opt-In）** | 仅适用于**刚体、光照稳定、且具备实际相机平移视差的高精写实 / 3A 密集静态场景**（`🟡 L2` 条件支持） | 标准 3DGS `.ply` 资产 + Blender 5.2 KIRI GPU 自由运镜工程与新视角成片 | **需用户明确授权从原片多帧反演辐射场**；有效自由运镜角严格受原片相机平移基线约束（纯旋转段仅约 `±6°~8°`，超出即拉丝穿帮）；不适合重打光或修改内部拓扑 |

## 二、 三级复刻能力边界分级（L1 / L2 / L3）

| 等级 | 标识 | 定义 | 适用范围 | 验收与交互要求 |
| --- | --- | --- | --- | --- |
| **L1：高精度可编辑复刻** | 🟢 | 具备完整逆向精测脚本与目标引擎可编辑重建管线，可做到高保真 1:1 复原 | 2D/2.5D 平面 UI 与动态图形、字形排版、硬表面/建筑/模块化/体素/风格化/棚拍产品 3D 场景、标准 PBR/三渲二与门控光学合成、混合型 `2D over 3D`、原混音时间轴对齐 | **全段 🟢 时不额外阻断**，简述边界通过并按流程确认派工与返修设置；使用子 Agent 时先确认具体模型与 Reasoning Effort；验收执行留出锚点像素误差及 `scene3d` 双向闭环复测 |
| **L2：需验证资源或技术条件** | 🟡 | 可精准还原相机、构图、节奏、光色与空间骨架，具体可达精度须结合物理前提和资产验证 | 中等复杂度有机/曲面交通工具与道具、简化方块/低模角色动作、程序化水面/雨雪/简单植被分布、强折射/次表面/复杂焦散材质、无原字库文件的近似字体；以及**高精写实/3A 密集静态场景的 3DGS 辐射场重建**（须刚体静光、且运镜角度受原片平移基线约束） | 检查所需资源、重建路线及其物理条件。3DGS 须说明源帧反演授权、视角范围与重打光限制 |
| **L3：超出当前高精度复刻边界** | 🔴 | 当前无法在禁止复用原片像素的前提下，以可编辑工程实现 1:1 高保真原生复刻 | 实拍真人表演/口播/微表情、传统手绘逐帧 2D 动画（作画/番剧/形变残影）、影视级写实角色/生物雕刻绑定与毛发布料解算、重度物理 VFX 动力学（流体/爆炸/浓烟/碎裂）、大幅度动态变焦（Dolly Zoom）/ FPV 高速翻滚穿越机与无人工直线的纯有机航拍（山川云海）、奢侈品/汽车 A 级曲面与未绕拍单体 `360°` 特写重打光、强非线性失真（重度 Glitch/万花筒/鱼眼强畸变/全屏粒子转场/高频闪切整帧模糊）、复杂实拍自然景观/人群纪实、几何闪烁的 AI 生成视频、非原声重制作曲/配音 | 核对其他引擎、已有资源及可独立重建的部分。仍缺必要资源时按手册询问用户，受影响项保留待补资产或未达标状态 |

## 四、 混合视频的分段定级示例

真实视频常同时包含多种画面类型，**必须按镜头/图层分别定级，不要一刀切拒接整条视频**：

- **示例 A（纯 2D UI 教学片）**：全片均为白底打字、网页卡片推拉与标注动效 $\longrightarrow$ 全段 `🟢 L1` $\longrightarrow$ 简述通过边界检查，用[开工选择问卷](workflow.md#开工选择问卷)合并展示独立问题，档位首推精细复刻，模型与推理强度各列一题。
- **示例 B（3D 片头 + 真人口播 + 网页演示）**：
  - `00:00–00:06` 三维街景和招牌可独立建模，车辆与行人需核查模型、动作和多角度参考。
  - `00:06–00:18` 真人出镜口播 $\longrightarrow$ `🔴 L3`（实拍真人表演超出原生复刻边界）
  - `00:18–00:30` 网页界面放大与打字动画 $\longrightarrow$ `🟢 L1`（可 Remotion 1:1 复刻）
  - 对口播段先查已有工程及用户实拍素材，明确需要哪段表演。未核实素材情况时，仅询问资源；可制作的街景与网页镜头按 1:1 推进。
- **示例 C（实拍电影预告片 / 番剧高燃剪辑，用户仅要求「拆解这个视频」）**：
  - 用户意图为**拆解分析**而非复刻 $\longrightarrow$ **不阻断**，完整交付镜头表、声画卡点与光色分析，仅在报告末尾用 2–3 句附注「如后续计划复刻，本片涉及实拍/手绘作画（🔴 L3），仅标题卡片与声画时间轴适合直接复刻」。
- **示例 D（高精写实中式石亭/3A 密集场景，用户要求「做视频 + 不同视角自由运镜」）**：
  - 先核查原片是否含非刚体特效/光照突变/动态前景，并用 `gs3d_pipeline.py` 评估相机平移基线：
    - 若目标是在原片采集轨迹附近做平稳推镜、轻度拉升或 `±8°~12°` 弧线视差 $\longrightarrow$ 走 **`CAP-3D-PHOTOREAL-3DGS`（🟡 L2，需用户同意 3DGS 路线与视角锥边界）**，实测基准见 [石牌坊 3DGS 基准](pavilion-3dgs-benchmark.md)；
    - 若目标是围绕某个未绕拍过的近景单体（如单根盘龙柱）做 `±45°~360°` 特写环绕或重打光 $\longrightarrow$ 提前告知纯视频 3DGS 会在 `±15°~20°` 起出现未观测面拉丝，必须改走 **`CAP-3D-IMG2MESH`（Image-to-3D 实体网格路线，目前需外部工具/素材）** 或采用「近景实体网格 + 远景 3DGS 环境」混合方案。

每当为 `h2o-video-decompose-distribution` 新增工具、模型或重建管线时，按以下 3 步同步能力边界：

1. **升级注册表条目**：在本文件第三节将对应 `CAP-*` 的等级与状态更新（例如 `🔴 L3 / planned` $\to$ `🟡 L2 / partial` 或 `🟢 L1 / supported`），写清新的脚本入口、验收标准与残留限制；
2. **补充运行手册与基准案例**：在 [workflow.md](workflow.md) 登记命令参数与验收门槛，并在 `references/` 下补充 1 份实测案例；
3. **保持主入口稳定**：[SKILL.md](../SKILL.md) 的前置能力评估流程和交互门控自动引用本表，无需推翻核心交互框架。
