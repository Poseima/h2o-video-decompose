# 视频拆解分发版

本分发版支持 macOS 和 Windows。Linux 暂不支持。首次使用先读[安装与验证](INSTALL.md)。按本次任务安装基础拆解、可选音频或可选 3DGS 所需的工具。脚本路径相对于 Skill 根目录解析，原片和输出路径由项目提供。

先从用户已指定的素材、范围和用途开始。只要能读取素材，就实际解码和检查。用户只说「拆解这个视频」时，默认覆盖全片画面和声音，交付镜头与内容时间线、带依据的音效和配乐对应表、分轨及试听。用户限定范围或维度时按其要求处理。「逐帧」「精确」「1:1」的指定片段按帧精测。续测沿用同一源文件、源帧号、源时间轴和跨界镜头的参考帧。

## 计划与沟通

默认以简体中文命名所有子代理、编写派工说明、命名新建交付文档（文件名及标题），并撰写进度消息、报告及验收结论。用户指定其他语言时全套随之切换。模型名、软件名、命令和工具固定标识保留原名。宿主限制内部标识时，在任务表登记对应的显示名，面向用户引用显示名。

**复刻任务固定采用主从 Agent 协作模式（禁用单 Agent 模式），普通对话和计划模式都默认推荐精细复刻。** 总负责人专职预览扫查、能力边界评估、共享资产核验、任务队列调度、总装与整片终验；盘点、独立建模与各分段精测/制作/返修必须派发给独立子代理，严禁总负责人单 Agent 包办全程（纯拆解/分析任务不建模也不复刻时，仍允许总负责人直接跑脚本交付）。预览原片后，优先用当前模式可用的 Ask User Questions 控件，将可以同时回答的未决事项放入同一份问卷。每个决定单独成题，推荐项排第一，用一句话说明本片的取舍。控件每批最多三题时，首批问技术路线、复刻档位、子代理模型（路线已确定时用推理强度、最大并发数或返修轮数补位）。档位首选「精细复刻（默认推荐）」，每位分段负责人最多负责 2 秒。无控件时在同一条消息列出多道编号题，允许一次回复多个答案。详见[开工选择问卷](references/workflow.md#开工选择问卷)。

沿用用户已明确的选择，集中补问适用缺项（子代理模型、推理强度、最大并发数与适用的资产、返修问题均为必答项，不提供跳过选项）。全部适用项有回答后，才展示最终计划和[开工分工确认表](references/workflow.md#开工分工确认表)。用户确认开工后，才可首次派发分析、盘点或制作任务。实际派发成功后报告本批负责人、范围、模型、推理强度及剩余排队人数。

优先使用宿主的计划模式；无法主动切换时，在对话中完成同样的计划与确认。纯拆解先简述范围、方法和交付物，需求明确即可分析。复刻先扫查完整目标范围，再研究最难镜头的技术路线，核验用户环境，与用户确认后派工。详见[能力边界预检与预期对齐](references/workflow.md#能力边界预检与预期对齐)。

所有面向用户的报告和交流都先说结论，给足理解结论所需的背景。指出哪一段、哪个主体、观察到什么、对结果有什么影响。需要用户决定时，列出推荐选择和取舍；已有决定直接沿用。用短段落或简表，删去重复提醒、过程流水账和与本次判断无关的防御性说明。影响选择的限制、未验证项和未通过项在正文点明，详细数据链接到底表。

## 扫查

1. 用 FFprobe 确认视频流、编码分辨率、旋转信息、逐帧 PTS 和时长。时间以源第一帧为零点，帧范围左闭右开。可变帧率用实际 PTS，缺失或不可靠时标出。
2. 运行 scripts/decompose.py 的 scan，生成故事板、候选切点邻帧和全帧索引。对照连续画面与切点邻帧。高灰度差也可能来自摇移、闪光或覆盖层，低灰度差也可能是匹配剪辑。密集快切缩短扫描窗口、增加候选数，逐帧排查。淡入、叠化和翻页给出过渡区间。
3. 记录切镜、转场、内容更新、同镜内运动和分层动画。利用跨内容更新可见的背景或边框验证镜头是否连续。按用户用途记录构图、遮挡、文字、光色和节奏。把有声画对应的切点、入场、接触、峰值和停止登记在源帧上，按[声音拆解与声画对应](#声音拆解与声画对应)逐个核对。
4. **场景范式自动判别与管线分流**：扫查后按每个镜头的几何与光学特征（或运行 `decompose.py scene3d` 读取 `scene_paradigm_classification.detected_paradigm`）先行判别场景类型，分别走对应的精测与复刻管线，严禁混用：
   - **`2D_PLANAR_UI_MOTION`（2D/2.5D 平面动态图形、白页打字、网页/卡片推拉、UI 录屏）**：大面积纯色背景（直方图前两箱占比 $>68\%$）、单平面 2D 单应性矩阵 $H_f$ 即可解释全场运动（`holdout_p95_px <= 2.75`）$\longrightarrow$ 走原有的 **[连续动效](#连续动效) + [逐帧精测 `measure`](#逐帧精测) + [字体与美术合成精测](#字体与美术合成精测)**（接入 Remotion / AE / Canvas / 2D 图层工程）；
   - **`3D_BLENDER_SCENE`（三维建模渲染场景、街景建筑、三维产品、体素/三渲二/体积光空间）**：具有连续曲面明暗梯度、三维平行线消失点汇聚或轴测立体块面、多深度层运动视差（`P85/P20 > 1.35` 或单平面拟合 `holdout_p95_px > 3.5`）、体积雾光晕衰减 $\longrightarrow$ 走 **[三维场景与 Blender 逆向精测 `scene3d`](#三维场景与-blender-逆向精测)**（接入 Blender 三维工程）；
   - **`HYBRID_2D_OVER_3D`（三维底景 + 画幅固定/平面悬浮的 2D 文字、歌词或 HUD 界面）** $\longrightarrow$ 三维底景与灯光走 `scene3d`，叠加的 2D 文字、光标或 UI 走 `measure` 与[字体与排版](#字体与排版)，分层独立重建后合成。

## 能力边界评估与前置沟通

扫查生成故事板并查看代表帧后，**在进入耗时精测、建模或派工之前**，先对照[能力边界矩阵与注册表](references/capabilities.md)并结合脚本输出的客观可重建性信号（`reconstructability_signals`），对目标范围逐镜/分层做三级能力定级：

- **🟢 L1（高精度可编辑复刻）**：2D/2.5D 平面 UI 与动态图形、排版与字形匹配、硬表面/建筑/模块化/体素/棚拍产品 3D 场景、标准 PBR/NPR 与门控光学合成、混合型 `2D over 3D`、原混音对齐。
- **🟡 L2（需验证资产或技术条件）**：中等复杂有机道具或曲面载具、简模/方块角色、程序化水面/雨雪/简单植被、强折射焦散材质、需核实字库或矢量稿的资产；以及**高精写实/3A 密集静态场景的 3DGS 辐射场重建**（须刚体静光段，且安全新视角角严格受原片相机平移基线约束，纯旋转段仅约 `±6°~8°`）。
- **🔴 L3（超出当前高精度复刻边界）**：实拍真人表演与口播微表情、传统手绘逐帧 2D 动画（番剧/作画/形变残影）、影视级写实角色/生物骨骼绑定与毛发布料、重度物理 VFX（流体/烟火/爆炸/破碎/布料）、动态光学变焦（Dolly Zoom）/ FPV 高速翻滚穿越机与无人工直线的纯有机航拍（山川云海，焦距退回 `35mm` 先验）、奢侈品/汽车 A 级曲面与未绕拍单主体的 `±45°~360°` 特写环绕重打光（需 Image-to-3D 网格）、强非线性失真与极端视效（重度 Glitch/万花筒/鱼眼强畸变/全屏粒子转场/高频闪切或整帧严重模糊）、剧烈手持重度遮挡或几何闪烁的 AI 生成视频、非原声重制作曲/配音。

按用户任务意图执行对应的前置交互策略：

1. **仅要求「拆解 / 分析」**：几乎所有视频都能完成镜头切点、构图运镜、光色与声画拆解，**不阻断流程**，直接全段分析；交付报告末尾附一段简短的「后续可复刻性简评」，提前标出哪些片段适合后续复刻、哪些属于 🟡/🔴。
2. **要求复刻**：指定范围默认以 1:1 为制作与验收目标。逐镜核对已有资产，主动发现本次会话可调用的工具和相关技能。缺少桌布、插画、纹理或透明前景时，先查内置 Image Gen 或其他可用生图能力；文字、UI、拖影和三维运动分别评估原生图层、程序化动效和建模。计划中写明选用的路线、试做对象及验收方法。执行时用已授权的工具实际试做，在成片尺寸、遮挡和出现时长下与原帧对照，达标后共享复用。L2/L3 只用于定位需验证的难点。
3. **确有资源缺口**：指出时间段、资产、影响及已核实的路线，只问用户能否提供具体资源或等效参考。只有用户明确确认资源无法提供，且经核验仍无可行的 1:1 路线，才可就这一资产说明替代做法和可见差异。获得用户另行明确同意后方可执行。未获同意的缺口记为待补资产或未达标，其余范围继续按 1:1 推进。

详细能力注册表、分段定级示例与前置评估模板见[能力边界矩阵](references/capabilities.md)与[能力边界预检与预期对齐](references/workflow.md#能力边界预检与预期对齐)。

## 原片重点效果与验收

开工前先完整播放原片，逐镜写出最影响观感的效果，再用慢放和原尺寸裁片补短暂细节。用户点名的差异直接列为必验项。每项记录主体、时段、原片依据和可观察的通过条件。同一效果跨责任段共用一个标识。按效果选用运动、透视、景深与拖影、质感、遮挡或声画检查；新效果也须留有专项证据。详见[重点效果清单与逐项验收](references/effects.md)。

三档复刻均对每段实际导出及整合成片运行 `decompose.py effects`。证据不足记为待复核，需返修项回原负责人。交付须同时具备逐镜清单、逐项结论和整片连续性报告。

## 连续动效

| 任务或画面线索 | 分析深度 |
| --- | --- |
| 整片概览、镜头表或内容时间线 | 扫查全段，记录动效的起止区间、可见变化和代表帧。普通单层淡入淡出、简单显隐以起止和代表帧交付。 |
| 用户点名要拆某段动效，要求该段逐帧或高保真还原，或反馈某时点的节奏、观感有偏差 | 直接对相关片段做分层逐帧精测。把用户给出的时点作为定位线索，窗口覆盖动作前的稳定状态到动作完成、趋稳或出画。 |
| 整段复刻 | 先扫查全段。多层错峰、轮廓变形、沿路径逐段显露、停顿后再起动、接触回弹、残影，以及被推拉或摇移盖住的局部动作，触发该片段的分层逐帧精测。已有复刻时先按源 PTS 对齐原片与旧版，优先核实可见差异。 |

1. 原速连续播放找动作节奏，再慢放看前后阶段、参与对象和层间先后。有旧版时同步对照。局部帧差可提示候选，用连续画面和邻帧确认事件。
2. 用稳定结构核对整体运镜。页内动效按参考帧逆投影，画幅固定层直接在画幅坐标测量，独立平面各自定位。给每层选能区分动作的量，例如画线端点、变形轮廓点、部件角度。几何变化、显露或淡化、反馈状态各自跟踪。
3. 将各层轨迹对齐到源帧号和 PTS。记录参考坐标、单位及适用的起动、峰值、停顿、层间延迟、回弹和趋稳。用动作前稳定段的波动判断变化是否可信。遮挡、配准不稳或量值不可辨时，保留可见事件区间或留空，标记复刻采用的插值或手工关键帧。

测量示例、记录字段和连续对照方法见[使用手册的连续动效部分](references/workflow.md#连续动效短窗精测)。

## 逐帧精测

1. 在每段找可跨帧定位的固定结构，例如页框、背景或固定文字。选一个清楚且覆盖范围大的参考帧，计划中写入稳定跟踪区、排除区、清晰度分区和测量锚点。参考帧出视野时，登记相互有重叠的中间帧。
2. 运行 scripts/decompose.py 的 measure。双向光流初始化，模板相关细化，以空间分块留出点比较相似、仿射和透视模型。接力配准的留出误差只衡量本次匹配。对多个深度平面、非刚体或局部转动，按图层、对象或可见局部重新拟合。缺少共同锚点、单帧镜头或纯过场时保留可见观察，无法求解的量留空。
3. 对关键转折选一个未参与拟合的独立检查，例如候选框角、页缘、标题栏或图标。先测静态平面，再测活动项，必要时通过逆投影换算到同一参考坐标。身份不确定时留空。参考点出视野后检查外推误差。
4. 用可比区域内的 **10–90% 边缘过渡宽度**描述可见模糊，记录 P30、样本数和相邻区域的差距。标注较锐区域及证据，留意笔画、压缩、缩放、拖影和合成的影响。遇到三维场景或需用 Blender 复原的片段，转入[三维场景与 Blender 逆向精测](#三维场景与-blender-逆向精测)定量反解焦距、三维位姿、材质、灯光、体积雾及后期光学参数；无法由几何或光度约束唯一定解的分量再列为推断或未知。
5. 复核段首、段尾、切前切后及速度、清晰度和投影异常帧。至少抽查一张实际覆盖图。核对帧号、参考帧、有限数值和缺测。长镜头可用带重叠的窗口分析，保留局部参考和注册误差，有共同锚点时再统一坐标。

## 三维场景与 Blender 逆向精测

针对由 Blender 等三维软件制作、或需要用 Blender 建模渲染还原的视频（涵盖三维建筑与街景、硬表面产品展示、Geometry Nodes 动态图形、三渲二/低多边形/体素风格场景），运行 `scripts/decompose.py scene3d` 从视频像素中定量反解以下 **6 大通用三维维度**，再接入 Blender 工程：

| 三维还原维度 | 实测与定量反解方法 | Blender 接入参数 |
| --- | --- | --- |
| **1. 相机与投影几何** | 提取场景三维平行线簇交汇求消失点 $(VP_x, VP_y, VP_z)$：平行线不交汇（交角 $<0.8^\circ$）判定为正交/轴测 `ORTHO`，交汇则由正交消失点约束求解 **36mm 等效焦距 $f_{\text{mm}}$** 与相机俯仰 `Pitch`、翻滚 `Roll`；检测 **宽银幕画幅遮罩（`letterbox_detected` / `active_content_aspect_ratio`）** 与 **边缘镜头几何畸变趋势（桶形/枕形/直线）**。对关键三维平面构件量取四角，由对边投影长度比直接解出 **透视缩短深度比 $D_L / D_R = h_R / h_L$**、相机空间 3D 顶点坐标、表面法线与显式对焦距离 `focus_distance_m`。 | `Camera.type` (`PERSP` / `ORTHO`)、`lens` (mm)、`rotation_euler`、画幅裁剪/镜头畸变、构件四角 3D 顶点坐标、`dof.focus_distance` |
| **2. 几何拓扑与建模范式** | 对构件做透视修正（Perspective-Correct）正交展平。用跨帧微视差残差和笔画/结构交叉处的色相留存率判定 **真 3D 挤出/置换层级（前景层 $+z_2 >$ 中景层 $+z_1 >$ 底板 $0$）** 与 `Normal/Bump` 凹凸；用多尺度高斯差分脊线（DoG Ridge）提取保留空心内腔的分层高度遮罩；用二维梯度自相关检测 **模块化阵列周期（`Array / Geometry Nodes` 步长与行列数）** 及硬表面倒角 `Bevel` 宽度。 | `Solidify` / `Extrude` / `Displace` 修改器强度、前后分层 `z_offset`、`Array` 步长与数量、`Bevel` 宽度 |
| **3. 材质、特殊光学子类型与描边反演** | 在线性光空间区分 **三渲二 `Shader to RGB`**、**`Principled BSDF`** 与 **`Emission`**；估算 **`Roughness` 中位值及噪波区间**、**`Metallic`**、贴图插值（`Closest`/`Linear`）及 **特殊物理材质子信号**（卡通色阶与暗部色偏 `toon_shading_profile`、清漆/亮漆尖峰 `specular_and_clearcoat_profile`、次表面散射明暗交界饱和增益 `sss_or_translucency_hint`、玻璃折射辅助提示 `transmission_glass_hint`）；在非边缘表面内部做 **多尺度 DoG 纹理谱（`2~5px` / `5~16px` / `16~48px` + 磨损斑点比）** 区分光滑/哑光/粗做旧；在 HSV 明度通道检测 **风格化暗色轮廓描边（`stylized_ink_outline`）** 并量出线宽。 | `Principled BSDF`（严禁非自发光面混大比例 `Emission`）、按需配置 `Coat Weight` / `Subsurface` / `Transmission` / `ColorRamp` 阶数、多尺度噪点与 `Bump`、按实测开启 `Line Art / Freestyle / Inverted Hull` 描边 |
| **4. 灯光色温、硬度、大气雾与地面反射** | 反推主光方位角、**主光仰角（顶光/侧光/底光）**、线性 **主辅光比** 与 **主辅光冷暖色温分离（`split_tone_lighting`）**；检测物体轮廓的 **逆光/轮廓光（`rim_backlight`）**、**局部自发光对邻近几何的间接彩光溢散（`emissive_indirect_spill`）**、非光源区暗部死黑占比、**4 象限局部动态范围** 与阴影 **半影过渡宽度 $w_{10-90}$**；同时覆盖 **局域光源体积散射（`volume_fog`）** 与 **白日/远景空气透视深度雾（`daylight_depth_haze`）**；以方向无关结构张量检测 **镜面/水面或斜向光泽表面反射（`ground_reflection_profile`）** 及 **径向暗角（`vignette_profile`）**，并输出机器可读的 **`recommended_blender_render_requirements`**。 | 按物理光传输需求配置引擎与弹射（有间接溢光/体积雾/复杂反射强制 `Cycles`；禁用关光追 EEVEE）、按硬度/仰角/冷暖色温配置与主体尺度相称的主/辅/轮廓光（禁超大泛光洗平或手画假阴影）、按需启用 `Principled Volume` / `Mist Pass` 与实景反射 |
| **5. 三维运动、微抖频谱与跨帧动态** | 识别 **满帧连续 vs 抽帧定格（`Stepped` / 12fps）** 与 **相机/前景混合帧率（`mixed_cadence_detected`）**；剥离 **多深度视差层（`P85 / P20`）**；分析跨帧加速度与反向振荡频谱区分 **手持低频漂移 vs 撞击高频震动（`camera_shake`）**；在宏静止区域检测 **定格纸纹/手绘线条沸腾（`texture_boiling`）** 及窗口内 **曝光/色温时序闪烁（`temporal_exposure_flicker`）**。 | 关键帧插值（`BEZIER`/`CONSTANT`）、多深度层 Z 轴、相机 Noise F-Curve 抖动、定格随机纹理种子与灯光曝光动画关键帧 |
| **6. 渲染色彩与特异光学合成管线** | 验证 **`AgX` / `Filmic`**；按原片实测生成 **19 项 `lookdev_feature_gates` 证据门控开关**与 **`compositor_glare_tier`**（`NONE` / `SINGLE_SOFT_GLOW` / `DUAL_NEAR_AND_BROAD`）；实测 **全画幅胶片/纸纹颗粒（`global_grain_rms`）**、**胶片高光红晕（`film_halation`）**、**宽银幕水平拉丝炫光（`anamorphic_streak`）**、**2D FFT 周期性扫描线/漫画网点（`CRT_SCANLINES` / `HALFTONE_DOTS`）**、方向性拖影 **`Motion Blur Shutter`**、四角径向 **`Dispersion`** 及 **`Lift / Gamma / Gain`**。 | `AgX` 视图变换、按 19 项 `lookdev_feature_gates` 条件启停的 `Principled Volume` / `Mist` / `DOF` / `Motion Blur` 及单层或双层合成器 `Glare` / 红晕 / 拉丝 / 颗粒 / 暗角 / `Lens Distortion` / `Color Balance`（跨明暗/辉光工况时按帧动态过渡或分场景） |
| **7. 3D 物件拆解与逐物件独立材质 BOM** | 自动结合显著主体、自发光连通域、光流残差聚类与 `--objects-plan` 提取代表帧的物件候选；逐件计算 **画幅框、相机空间 3D 坐标 `(X,Y,Z)` m、物理尺寸 `W×H×D` m、运动速度矢量**，并对每个物件裁剪区独立运行 **逐物件材质画像（`roughness`、`surface_finish_class`、`bump`、`metallic_hint`、`ink_outline`、`clearcoat_hint`）**，防止混搭材质场景被全图平均抹平；切出 `objects/obj_XX.png` 并生成候选工作包（`WP1..WP4`）。 | `assets_bom.json`、`assets_bom.md`（每件带独立材质参数）、`objects_3d_map.png`、按 `Col_WP*` 并行建模并按逐物件独立材质着装后 `Link/Append` 总装 |

命令参数、JSON 字段及实测指标到 Blender 节点的换算公式见[使用手册的三维场景部分](references/workflow.md#三维场景与-blender-逆向精测)。

## 实测复刻

分段复刻开工前，按目标范围向用户列出三档。三档都以 1:1 为目标，执行相同的分段与整片验收。

| 复刻档位 | 每位分段负责人最多承担 | 取舍 |
| --- | ---: | --- |
| 精细复刻 | 2 秒 | 便于逐项核对短动作、遮挡与运镜，交接最多。 |
| 均衡复刻 | 5 秒 | 兼顾细节和制作成本，适合动作密度适中的片段。 |
| 快速复刻 | 10 秒 | 派工较少，短动作和局部差异更容易遗漏。 |

档位题按精细（默认推荐）、均衡、快速排序，按实际片长列出三档预计段数。并发尚未选定时，批次数用明确标注的假设估算。询问返修轮数时，结合动作和接缝难度给出至少一轮的可选方案。

总负责人维护同一项目根目录、共享资产清单和任务表。复刻一律按主从 Agent 分离执行（即使目标范围仅 1 个分段，也由总负责人统筹与独立终验、独立子代理负责建模与分段制作，严禁退回单 Agent 包办）。盘点、建模、分段制作分别排队，各阶段实际并发取用户确认上限与可用名额的较小值；名额紧张时按队列串行顺延（最低并发 1 接力）；若宿主环境不支持或长期无法创建独立子代理，直接向用户说明阻塞并暂停复刻，禁止静默降级为单 Agent。详见[项目目录与共享资产](references/workflow.md#项目目录与共享资产)。

1. Blender 项目由盘点子代理回看完整目标范围，逐件登记所有可见资产。总负责人跨镜去重，将截图、名称、所有出现时段及重建或替换方式整理成简表，请用户确认。见[资产盘点与独立建模](references/workflow.md#资产盘点与独立建模)。
2. 资产清单确认后，独立建模子代理按件负责，交付模型、材质和必要绑定。总负责人核验并发布完整共享库后，才启动另一批分段子代理。非 Blender 项目在路线确认后直接进入分段制作；混合项目的三维层走完整资产流程，二维层共享字体、组件和合成设置。
3. 每位分段子代理在同一项目只领一个正式时间段，按所选上限划段，优先贴合切镜或动作边界。原负责人完成该段分析、精测、制作、导出、对比、返修和复测。段内使用最长两秒的精测窗，跨段交接共用资产版本、坐标、相邻参考帧和动作状态。
4. 原片画面仅用于观察、测量和审片对照。纯参数化复刻工程（2D UI / 排版 / 硬表面与风格化 3D）及成片禁止直接使用原片片段、静帧、截图、裁切、抠图或其他原片像素，须独立重建关键元素。新生成的素材可以作为可替换图层，交付时注明哪些内部元素需要回到素材制作阶段才能编辑。**例外（需前置授权）**：当用户明确选择 **3DGS 辐射场重建路线（`CAP-3D-PHOTOREAL-3DGS`）** 用于高精写实/3A 密集静态场景的新视角运镜时，允许使用 `scripts/gs3d_pipeline.py` 从原片刚体多帧反演 3D 高斯辐射场（`.ply`），但必须提前说明视角锥边界与不可重打光限制。
5. 分段负责人缺工具时，将资产、时间段和已有证据交回总负责人。总负责人核查自己或其他制作角色的能力，安排试做并将达标版本发布到共享库。试做或技术核验仍表明确有缺口时，才按[能力边界评估与前置沟通](#能力边界评估与前置沟通)询问用户。
**有对照原片的审片必须通过镜头连续性验收。** 每次审片以实际导出视频运行 `decompose.py continuity`，检查每对相邻帧的运镜、画面结构、光色变化和停顿。逐项查看局部入画、消失、遮挡和错时的带框证据，核对主体是否能从画框或遮挡边缘连续追溯。检查持续部件的局部外观、遮挡前的最后可辨轮廓，以及同一主体的入画时刻。逐项核对原片和复刻的框是否落在同一主体，记录每个局部候选的复核结论。局部返修包含两端接缝，分段合并后重新对整条交付片执行。只有本次导出的报告为「通过」才能标记连续性合格。单帧抽检、分段通过或返修次数用完都不能替代这一项。未测区间与待复核事件在交付时逐项注明。命令、退出码与复核方法见[镜头连续性验收](references/continuity.md)。

6. 原负责人以每段首版实际导出对齐原片，核对原速播放、关键帧及接缝。三维逐段做双侧 `scene3d` 和 `compare --strict`，二维用 `measure` 比位置与时序、用 `lookdiff` 比外观，混合段检查两层及合成。每段至少一轮对比、记录差异、修正、重渲染和复测。首版不计轮数。适用检查均通过且无可修差异时保留证据，记录实际修改次数。轮数用尽仍有异常，记录未通过状态与时间点。
7. 总负责人合并为一个可编辑工程，从项目入口重新打开并导出整片，核对资产路径和版本、接缝、真实切点、素材来源和声画同步。原声默认作为独立、可替换的对齐音轨接入，用户另有要求时按其指定处理。实际修改一项关键元素并重渲染，确认编辑生效。对最终选定导出中有原片的范围重跑 `effects` 与 `continuity`，分列单项、分段与整片结论。摘要列出通过、需返修、待复核的段数，另列整片结论和异常接缝时间。
8. Blender 盘点时先读 `scan` 生成的 `lookdev-keyframes.json`，覆盖强光/发光峰值、高反差与暗调等全部光学工况运行 `scene3d`，将 `assets_bom.md`、`assets_bom.json` 和 `objects_3d_map.png` 用作候选与取样依据。建模、布景和验收按以下技术要求执行。
   - 已确认物件可按 `WP1..WP4` 分类交给唯一建模负责人，建入 `Col_WP*` 集合。总负责人在总装维护实用光源、环境补光与按需启用的大气、粒子及合成层。
   - **零渲染妥协铁律（No-Speed-Compromise Rendering Policy，方案 A）**：**绝对禁止为了缩短渲染时间（包括远程 GPU 节点离线/超时、本机算力较慢或帧数较多）而降级渲染引擎、关闭光追/全局光照、砍掉物理弹射、删除体积雾、压低采样至失真或简化多层光学合成**。严格遵循 `scene3d.json` 的 `recommended_blender_render_requirements`：
     - 凡原片实测包含 **局部自发光间接溢光（`enable_emissive_indirect_spill`）、体积散射（`enable_volume_fog`）或复杂镜面/湿面/透明反射（`enable_ground_reflection` / 玻璃折射）**，正式验收与交付成片**强制使用 `Cycles`**（且 `diffuse_bounces >= 2`、`glossy_bounces >= 2`、有雾时 `volume_bounces >= 1`，开启降噪与达标采样）；
     - 其余无上述多弹射需求的 PBR/NPR 场景，可使用 `Cycles` 或**开启 `use_raytracing = True`、`use_fast_gi = True` 与有效 `Light Probes` 的 `EEVEE`**；**任何非平面 3D 终稿一律严禁使用 `use_raytracing = False` 的无光追 EEVEE**；
     - 低采样/无光追快渲仅允许用于带明确标记的粗模几何对位试渲，不得作为验收或交付成片；远程 GPU 不可用时，按本机全质量渲染或先向用户说明耗时并请求决策，严禁静默降级。
   - **证据驱动的条件开关（Evidence-Gated Look-Dev）**：严格遵循 `scene3d.json` 中 `lookdev_feature_gates` 的 **19 项实测开关**（含 `emissive_indirect_spill`、`volume_fog`、`daylight_depth_haze`、`bloom_or_soft_glow`、`dof`、`motion_blur`、`lens_dispersion`、`emissive_materials`、`surface_grunge_bump`、`ink_outline`、`vignette`、`film_or_paper_grain`、`split_tone_lighting`、`rim_backlight`、`ground_reflection`、`film_halation`、`anamorphic_streak`、`texture_boiling`、`camera_shake`）与 `assets_bom.json` 中的**逐物件独立材质画像**——凡原片实测为 `true` 的维度必须按实测参数实装，不得留空或关闭；凡原片实测为 `false` 的维度必须保持关闭，严禁硬加原片不存在的雾、光晕、红晕、倒影、做旧、描边、暗角或颗粒；跨明暗或辉光工况的连续镜头必须对合成器辉光/曝光曲线做关键帧过渡或分场景布光。
   - **受光材质与真实光影铁律（严禁 `Emission` 替代打光、假阴影与大泛光洗平）**：对非自发光受光表面（纸板、漆面、墙面、石材、织物、塑料等），**严禁在材质中混入大比例 `Emission`（如 `MixShader(Principled, Emission, >0.15)`）充当亮度补偿**；必须通过与场景尺度相称的真实主/辅光（按 `shadow_penumbra_width_px` 与 `key_to_fill_linear_ratio` 匹配硬/软光，禁在强明暗对比场景中用多盏远超主体尺度的超大泛光灯洗平立体感）、真实光追间接弹射与反照率塑形，严禁贴纯渐变透明片冒充投影；程序纹理必须按 `surface_texture_profile` 的宏/中/微三频段配置可见尺度，避免单一超高频噪点被抗锯齿吞没；
   - **区分「几何对位核验」与「最终成片交付」**：量测几何锚点像素误差时可在临时无模糊预览状态下核验，但最终保存的 `.blend` 与交付成片必须恢复与原片 `lookdev_feature_gates` 及 `recommended_blender_render_requirements` 一致的完整光追、灯光、着色器与光学管线；
   - **工程静态 + 像素实测双向闭环复测门槛（Dual Closed-Loop Gate）**：
     1. **`.blend` 工程静态审计**：正式渲染验收前/后对 `.blend` 运行 **`decompose.py audit-blend <复刻.blend> --scene3d <原片scene3d.json> [--scene3d ...] --out <审计目录> --strict`**，无头校验引擎/光追/弹射/采样无降级、体积与单/双层合成辉光齐备，并预警超大泛光洗平与材质作弊；
     2. **像素双向闭环裁判**：对照 `lookdev-keyframes.json` 覆盖各光学工况代表帧，对渲染输出再跑一次 `decompose.py scene3d`，再运行 **`decompose.py compare <原片scene3d.json> <复刻scene3d.json> --strict --out <验收目录>`** 执行自动红灯裁判——校验全部 **19 项 `lookdev_feature_gates` 门控一致**、中调/亮部光度（`p50`/`p85`）、近场辉光（`near_bloom_linear_lum`）、远场体积散射（`far_volumetric_excess`）、**自发光周边彩光溢散（`emissive_spill_chromatic_energy`）**、**相对暗部死黑占比（`non_core_crushed_black_ratio`）**、**4 象限局部反差（`regional_tonal_contrast`）**、阴影柔和度（`shadow_penumbra_width_px`）、粗糙度、**磨损斑点双向误差**、**亮面/彩面分区细纹（`bright_surface_fine_rms`）**、**纹理坐标拉伸各向异性（`texture_stretch_anisotropy`）** 及 **同帧 `SSIM / Edge IoU` 与差异热力图 `compare_report.png`**；发现 FAIL 项即按约定轮数返修并复测，剩余 FAIL 逐项列入未通过记录。
   - **跨视频局部质感诊断**。原片与渲染有对应视频时，代表帧的 `compare` 自动附上「局部质感差异」。核对整段时运行 `python scripts/decompose.py lookdiff 原片.mp4 渲染.mp4 输出目录`。使用当前原片自动找选区、给出原尺寸对照与检测下限。先复核几何配准，再按排序做单变量 Blender 试渲染。同一裁片中的亮斑、暗带、纹理方向可能有多个成因，保留证据不足项。命令、证据解释与跨项目盲测方法见[局部质感诊断](references/local-appearance.md)。
   - **一步三维顶点定位与规范着色封装**：平面构件用实测四角深度比 $D_L / D_R$ 直接在相机空间插值定位；多层 3D 发光或浮雕网格用深色 `Principled BSDF` + `Alpha` 遮罩阻断后层光线防过曝；使用后景参考背板时按实测光晕衰减外扩擦除区，交付前调用 `bpy.ops.file.pack_all()` 打包依赖。
9. 经用户授权采用 **3DGS 辐射场重建**（写实静态场景的自由运镜）时，先按[安装与验证](INSTALL.md#可选-3dgs)检查 COLMAP、Brush 和可用 GPU。剔除非刚体扭曲转场、动态肢体、光照突变与静态水印边带。用 `scripts/gs3d_pipeline.py` 抽帧、解算相机并训练导出 PLY。检查 `baseline_analysis.recommended_safe_novel_view_budget`。近景主体的平移基线很窄时，若用户需要 `±20°~45°` 绕物特写，改用 Image-to-3D 网格路线。需要 Blender 成片时，将 PLY 导入兼容的 KIRI 3DGS Render 扩展并先试渲染一帧。Apple Silicon / Metal 的实测渲染步骤见[使用手册 3DGS 小节](references/workflow.md#4-高精写实静态场景-3dgs-本地重建与-blender-52-渲染gs3d_pipelinepy)。

任务交接见[分段派工与任务交接](references/workflow.md#分段派工与任务交接)。字段、坐标与误差核对见[复刻时读取哪些数据](references/workflow.md#复刻时读取哪些数据)。

## 字体与美术合成精测

用户要求精确解析这些维度时，沿用逐帧精测的源帧号、PTS 和参考帧，只测所需维度。先记录文字出现、状态切换、动画开始和趋稳、切镜等可见事件的首帧。之后测得的声画事件都对齐到同一源时间轴。

### 字体与排版

1. 找多个清晰、显露完整字形的帧，按所属平面逆投影到同一参考坐标。固定在画幅上的文字直接从源画幅取样。正文、标题、字幕、界面标签按用途取样，中文、拉丁字母、数字、标点和数学符号分别比较。
2. 将候选字体和字重渲染成相同的文字。对可辨识的单字按墨迹框对齐和归一化，用多个对比度阈值计算二值轮廓 IoU。在相同的位移和模糊容差下比较候选，记录逐字与汇总得分。输出候选与原片的轮廓叠图，标出能区分候选的笔画。分数接近、样本太少或笔画被模糊吞没时，只给能支持的字体类别、字重或候选范围。
3. 在未做逐字归一化的参考图上量墨迹高宽、字心节距、基线、行距和各文本块的相对字号，注明参考帧和像素尺度。含公式时另量括号高度、分数线与上下项间距、上下标相对位置。成片尺寸可作复刻目标，原工程的字点数和字体文件仍可能未知。

### 美术与合成

1. 在稳定的亮区、暗区和颜色区域取样，记录源帧、矩形范围、颜色空间和中位色。分别保存背景、正文、强调色和覆盖层的成片色值。用同一参考坐标量边界、圆角和间距。用边缘法向剖面量软边、阴影尾部或高光的可见宽度。对 2D 平面图形，原图层不透明度、模糊半径和灯光参数在缺少独立证据时可标为推断；**对 3D / Blender 场景，必须按 `decompose.py scene3d` 输出的 `lookdev_feature_gates` 与实测物理参数按需实装（实测为 `true` 的体积/光晕/景深/快门/色散不得漏关，实测为 `false` 的干净场景也不得乱加冗余特效）**。
2. 对能跨帧追踪的字幕、标记、边缘或局部纹理，同时记录其画幅坐标和页面参考坐标。比较哪个坐标下的位置或亮度剖面更稳定，据此判断层是固定在画幅、随页面投影，还是在页面内独立运动。底部暗化可在多个画幅位置取亮度剖面，并用跨运镜或跨切点数据复核。缺少相对运动时保留层归属的不确定性。
3. 选中条、下划线、勾号等局部动画按[连续动效](#连续动效)确定测量深度。做精测时按动作量位置、尺度或可见面积，并抽查遮挡、模糊及分割阈值影响的原帧。

## 声音拆解与声画对应

默认用本地波形、频谱、瞬态和拍点数据核对声画；对节奏卡点片或 MV，可运行 `scripts/soundtrack.py beat-lock` 自动将音频瞬态/拍点与画面切镜、闪白跳变、运动冲击峰对齐并导出 `av_beat_lock.json` / `av_beat_lock.csv` 作为关键帧锁定依据。仅在确认当前模型和请求通道都支持音频输入时，才把音频作为模型输入。需要听辨而当前无法直接听辨的项目标为「待听辨」，继续完成其余分析。分轨和试听片段以本地文件交付。

1. 用 `scripts/soundtrack.py prepare` 以原片首帧 PTS 为零点提取原混音。保留采样率、声道和电平，核对音视频流起始偏移。优先用已核实对齐的独立轨或同源分轨。其余用 **Bandit v2 多语种权重 + ELUATE** 本地分离对白、BGM、音效，Apple GPU 可用时优先，其他情况走 CPU。保存分轨、模型和时间轴证据。缺少原声或分轨失败时，完成可做的分析，并登记缺测或原混音回退。
2. 逐段比对原混音、音效轨和音乐轨的本地波形、短时频谱和频带包络，用瞬态定位键击、扫声、提示音、撞击等候选。回看切镜、入场、接触、峰值和趋稳，核对声音与动作阶段的对应关系。记录起音、峰值、可辨尾音以及它们起到的预告、强调或延续作用。允许成组短击、一声跨多镜、同一动作叠音效和音乐。弱音、串音及有多种归属的声音保留候选。素材名仅在有独立证据时登记。
3. 有已对齐的原版 BGM 时优先用它找拍，否则用分离出的音乐。用 Beat This! 生成每拍和小节首拍候选，对照原混音的波形、频谱和音乐电平曲线，核对鼓点、入场、渐强、停顿、换段和收尾。检查切镜、文字入场或动作峰值与哪个音乐事件对齐。节拍不稳时记录可辨的音乐变化。时间接近仅提供配对线索，结合前后节奏、重复声纹和画面动作判定。
4. 用 `scripts/soundtrack.py match` 导出核对过的对应表和同步试听文件。用「声音时间减画面时间」计算偏差，注明选了起音、峰值、节拍或段落边界。保留只有动作或只有声音的事件。音频可标到毫秒量级，画面精度受源帧间隔限制。精测时另记录频带、窗长、阈值、攻击段宽度和峰值或 RMS（dBFS），注明所测轨道。原声和分轨都保留对应时间，方便核对。

运行方法、时间约定和审核格式见[声画拆解使用手册](references/workflow.md#声画拆解与试听)。

## 交付

- 先给关键时间点、观察和数值。需要复刻时给出切点、固定层与活动层、节奏、画面轨迹和清晰度变化，并标明对原实现的推断。
- 声画拆解附全段对应表、对齐的原混音和可用三轨，以及关键段同范围试听。用代表例子解释音效和音乐分别怎样跟画面配合，列出低置信度、分轨串音及找拍缺测。
- 复刻交付包含可编辑工程、按请求渲染的成片，以及原片与复刻的代表帧对照。附经确认的资产简表（适用时）、分段与精测窗口清单，登记用到的实测数据、1:1 核验结果、待补资产或未达标项、用户明确批准的局部例外及对应时段、返修记录、素材的编辑入口、回退区间和仍可见的差异。 局部替代按获准范围单列，不能据此标记整片 1:1 通过。
- 纯拆解/分析交付在报告末尾附简明「后续可复刻性简评」，按 `🟢 L1 / 🟡 L2 / 🔴 L3` 标出各段若后续复刻的可行性与边界限制。
- 有原片的审片交付须注明实际导出的连续性结论与覆盖区间，附本次 `continuity.json`。任何待复核、缺测或需返修项均保留时间码；局部通过只适用于所测区间。
- 连续动效精测附分层事件表、逐帧观测及局部叠图或轨迹曲线。复刻时另附按源时间对齐的连续对照。
- 高精度解析交付切点表、逐帧 CSV、矩阵 JSON、曲线及原片核对图。需要审片视频时用 --annotated-frames 获得逐帧覆盖图，再按源 PTS 合成。注明缩放、缺测及精度。
- 做字体、美术或音效精测时，按所测维度附候选字体评分与轮廓叠图、版式尺寸与色板、图层轨迹与亮度剖面、带置信度的音频事件表及波形或频谱对齐图。需要试听或审片时附同范围原声和带原声的标注视频。表格保留源帧号、时间、参考坐标、取样区和单位，便于复算。
- 按用户指定位置或当前视频的本地活动目录保存分析。保留源文件和前次结果。续测合并前核对重叠帧和分界。

脚本参数、计划格式和复算方法见 [使用手册](references/workflow.md)。
